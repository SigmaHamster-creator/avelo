# Avelo demo video: script and shot list (target 2:50, must stay under 3:00)

Rules to respect while recording:

- Show the app actually running in the browser (screen recording). No mockups.
- No third-party music or logos. Record without music, or use audio you created yourself.
- Upload to YouTube or Vimeo as **Public** (or Unlisted only if the form allows; the rules say "publicly visible").
- Before recording: click **Demo Controls > Reset**, use Chrome or Edge, allow the microphone, and test it once.

|---|---|---|---|
