# English-only output

All application content, code identifiers, comments, documentation, sample/demo data, AI (and AI-fallback)
responses, validation messages, and submission materials for Avelo must be in English.

This applies to:

- Every user-visible string: labels, help text, button text, validation errors, error summaries, voice
  listening/transcribing/updating status text, clarification questions, booking status labels, demo scenario
  names, and the Demo Controls UI.
- Every fictional demo data value: caregiver/passenger/provider names, addresses, hospital names, special-request
  text.
- Every code identifier, code comment, and documentation file (requirements/design/tasks, README, Kiro usage
  write-up, video script).

Do not introduce non-English strings anywhere in the Avelo codebase or its documentation, including as
placeholders or examples, unless a user explicitly provides non-English content for their own project data (not
applicable to this project, which has no such content).
